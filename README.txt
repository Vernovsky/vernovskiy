МУЗЫКАЛЬНЫЙ ПЛЕЕР
Плеер создаёт один экземпляр Audio и использует music.mp3. По умолчанию звук выключен и включается пользователем. На устройствах, блокирующих автозапуск, воспроизведение начинается после первого действия пользователя. При переходах между разделами используется общий аудиоконтекст.
